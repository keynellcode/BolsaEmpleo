# Proyecto de Gestión de Puestos

Aplicación web full-stack para la gestión y visualización de detalles de puestos con interfaz moderna y transiciones suaves.

## Tecnologías

**Backend:**
- Java
- Spring Boot
- Maven

**Frontend:**
- JavaScript/React
- Tailwind CSS
- npm

**Base de Datos:**
- SQL

## Requisitos Previos

- Java 11+
- Node.js 16+
- Maven 3.6+
- npm 8+

## Instalación

### Backend

```bash
cd backend
mvn clean install
mvn spring-boot:run
