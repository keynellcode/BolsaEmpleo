# Proyecto de Gestión de Puestos

Aplicación web full-stack para la gestión y visualización de detalles de puestos con interfaz moderna y transiciones suaves.

## Tecnologías

**Backend:**
- Java
- Spring Boot
- Maven

**Frontend:**
- JavaScript/React
- Tailwind CSS
- npm

**Base de Datos:**
- SQL

## Requisitos Previos

- Java 11+
- Node.js 16+
- Maven 3.6+
- npm 8+

## Instalación

### ⚙️ Backend (Spring Boot)

1. Abrí MySQL Workbench
2. Ejecutá el script:
```bash
bolsa_empleo.sql
```

3. Abrí bolsaempleobe en IntelliJ
4. Editá src/main/resources/application.properties:
```bash
spring.datasource.password=tu_contraseña
```

5. Ejecutá BolsaEmpleoApplication.java

### 🖥️ Frontend (React)

1. Abrí terminal en bolsaempleofe
2. Ejecutá:

```bash
npm i
npm run dev
```
